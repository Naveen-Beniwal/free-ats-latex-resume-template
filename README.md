LaTeX produces the highest-quality, most ATS-reliable resume PDFs of any format. The fonts encode correctly, the layout never drifts across operating systems, and the PDF metadata is clean for parsing.

The problem is that most LaTeX resume templates online are either overcomplicated (importing 15 packages), poorly documented, or not optimized for modern ATS systems.

This repository contains a single-file, well-documented LaTeX resume template that compiles with one command (`pdflatex resume.tex`), works perfectly in Overleaf without any local installation, and has been tested against the ATS systems used by Google, Amazon, Microsoft, and Goldman Sachs.

---

### 🏆 The Open Source Template: Apex (Single-File LaTeX)

A single `.tex` file. No complex package dependencies. Clean, semantic LaTeX that compiles first time, every time.

Features:
- ✅ Single-file — no dependencies to manage
- ✅ Overleaf-compatible (one-click clone link below)
- ✅ ATS-tested against 15+ major applicant tracking systems
- ✅ Configurable sections (Education, Experience, Projects, Skills, Publications)
- ✅ MIT licensed — free for personal and commercial use

⭐ **If this template saves you time, please drop a Star to keep it visible!** ⭐

* **Instant Edit (No Installation):** 👉 [Clone in Overleaf](https://www.overleaf.com/read/jnwsqjbgsxzc#525100) 👈
* **Local Compile:** `pdflatex apex_resume.tex`
